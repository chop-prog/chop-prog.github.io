01 Product UI

Flowboard

A keyboard-first kanban board in the spirit of Linear and Trello: drag & drop, a ⌘K command palette, undo/redo for every action, filters, offline persistence.

  • React 19 + strict TypeScript; a normalised state with a pure, tested reducer
  • Drag & drop by mouse, touch and keyboard; one undo step per drag
  • 29 Vitest + Testing Library tests, CI with type-check and build

React · TypeScript · Vite · dnd-kit · Vitest

02 Graphics · WebGL2

Aurora

Real-time fluid dynamics in the browser. The Navier–Stokes equations are solved on the GPU every frame, and you stir the fluid with the mouse.

  • Raw WebGL2 and GLSL, no libraries: advection, vorticity, a Jacobi pressure solve
  • Debug views of the solver fields, presets, shareable settings in the URL
  • Microphone-reactive mode, adaptive quality, PNG snapshots

WebGL2 · GLSL · Web Audio · node:test

03 Game · Canvas

VOID PULSE

A neon twin-stick roguelite with its own engine: a warping spring-mass grid, bloom, a boss fight and music synthesised entirely in Web Audio.

  • Fixed-timestep loop, spatial hash, struct-of-arrays particles
  • Seeded daily runs, 15 upgrades, keyboard, gamepad and touch
  • 27 unit tests, installable PWA that works offline

How I work

I care about the parts of an interface users feel without noticing: responses that don't lag, keyboard shortcuts that just work, motion that helps instead of distracting, and states that never lose your work.

I like knowing how things work under the hood, so I don't mind writing a physics loop or a shader by hand. I also know when a good library is the right call: Flowboard uses React and dnd-kit for exactly that reason.

Every project here has automated tests, a README that explains the decisions, and a CI pipeline that deploys on every push.
